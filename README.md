# bOden Downloads

Offizielle Download- und Updatequelle fuer die bOden-App.

## Aktuelle Version

Die jeweils aktuelle Windows-Vollversion steht unter
[Releases / Latest](https://github.com/ivanthevil/bodenansprache-releases/releases/latest)
bereit. Bereits installierte bOden-Versionen verwenden weiterhin den kleinen
internen Patch-Updater.

## Plattformen

- Windows-PC und Windows-Tablet: dieselbe portable `.exe` mit vollstaendigem bOden-Funktionsumfang
- Android: separate Testapp **bOden Rueckbau** im Repository `boden-android-releases`; sie enthaelt nicht den vollstaendigen Windows-/Tablet-Funktionsumfang

In diesem Repository liegen keine Projektdateien, Fotos oder Kundendaten.
